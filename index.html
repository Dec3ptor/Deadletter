Nothing here is stored in readable form. Every post is sealed in your browser before it is sent. The server keeps ciphertext, timestamps and thread titles — it cannot read a post, and neither can anyone who opens this page without the code.

    Pick a thread, or start one. Every thread on the left is readable by anyone holding its code and by nobody else. Open one and you will see exactly what the server sees: sealed bytes, until you enter the code.

    Start a thread

    The title is public — it has to be, so the thread can be found. Everything posted inside it is not.

    There is no way to recover this. The code is never sent anywhere and is not stored — not by the site, not by the server, not by anyone. Lose it and the thread stays sealed for good.

    What anyone can see

    The thread titles, how many posts each one holds, how long each post is and when it was written. That is the price of a public board: the shape of the conversation is visible even when its contents are not. If the existence of a thread is itself the secret, this is the wrong tool.

    What the code does

    It becomes the key, in your browser, and never travels. A generated code carries 256 random bits and is used as the key directly. A code you invent is stretched with 600,000 rounds of PBKDF2, which makes each guess expensive but cannot save a code that was guessable to begin with — and since every byte here is public, an attacker can guess offline, forever, without anyone noticing. Use the generated one.

    Everyone with the code is equal

    There are no accounts and no owners. Anyone holding the code can read the thread and post to it, and a code cannot be taken back once given — the only way to remove someone is to start a new thread with a new code. Posts cannot be edited or deleted by anyone, including whoever wrote them.

    How it works sets out the whole design, including what it does not protect against.
