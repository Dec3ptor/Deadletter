    Pick a thread, or start one. Every thread on the left is readable by anyone holding its code and by nobody else. Open one and you will see exactly what the server sees: sealed bytes, until you enter the code.

    Start a thread

    The title is public — it has to be, so the thread can be found. Everything posted inside it is not. A 256-bit code has been generated for you; replace it only if you have a reason to.

    There is no way to recover this. The code is never sent anywhere and is not stored — not by the site, not by the server, not by anyone. Lose it and the thread stays sealed for good.

    What anyone can see

    Thread titles, how busy each thread is, and when. That is the price of a public board: the shape of a conversation shows even when its contents do not. Keep the secret out of the title.

    What the code does

    It becomes the key, in your browser, and never travels. Generate one and it is 256 random bits — not guessable by anyone, ever. Type your own and it is only as good as it is, and everything here is public enough to guess at privately for years. Use the generated one.

    Everyone with the code is equal

    No accounts, no owners. Anyone holding the code can read the thread and post to it, and a code cannot be taken back once given. Nothing can be edited or deleted afterwards, by anyone.
